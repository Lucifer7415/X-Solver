# Setup guide

### Working demo

Install Node.js 20+, then run `cd mealbridge`, `npm start`, and `npm test`. Open `http://localhost:3000`. This is the runnable implementation.

### Target full-stack services

The frontend, TypeScript backend, Prisma database, FastAPI service and deployment entries in this directory are scaffolds only. Install their package dependencies, configure `.env`, add migrations and providers, and implement each placeholder before attempting a multi-service launch. Do not use the example demo passwords or local JSON database in production.
