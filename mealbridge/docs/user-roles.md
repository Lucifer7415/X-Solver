# User roles

- **Administrator:** verifies organizations, monitors operations and audits delivery exceptions.
- **Restaurant/hostel donor:** posts surplus with quantity, handling and expiry; tracks allocations.
- **Food bank/NGO recipient:** maintains demand, capacity, dietary needs and receipt confirmation.
- **Delivery partner:** maintains vehicle capacity and availability; updates assigned deliveries and reports failures.
- **Volunteer:** assists with permitted handoffs.

The working demo enforces server-side role and record checks for its implemented endpoints. The React and TypeScript scaffold does not yet implement a production authorization policy.
